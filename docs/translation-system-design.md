## 一、决策：为什么自建，不采购现成工具

四路调研交叉验证，工具生态对比（维度 C���结论明确：

| 方案 | 质量 | 术语一致 | 批量 | 交付定制 | 成本 | 结论 |
|------|------|---------|------|---------|------|------|
| DeepL | 高（通用好） | 内置 glossary（有限） | 有（API） | 弱 | 订阅/按量 | 通用好但定制弱 |
| CAT（Trados/memoQ/Phrase） | 高 | 强（TM+termbase） | 强 | 中 | 贵，学习成本高 | 过度工程化 |
| **自建 LLM 流水线** | **高（可注入 glossary+风格）** | **强（全可控）** | **强（脚本化）** | **最强（双语/飞书/Word 自选）** | **复用现成 LLM 网关** | ✅ **选这个** |

**决定性理由**：
1. **你已有 LLM 网关**（`127.0.0.1:8897` → DeepSeek-V4-Flash），翻译引擎零新增费用，直接复用
2. **科研翻译的命门是术语一致 + 学术语体**，自建可完全定制 glossary 注入 + 中文科研语体规范，DeepL/CAT 给不了
3. **交付形态自由**：双语对照 Word（fdocx）/ 飞书 / Markdown / 纯中文，直接衔接现有交付 skills
4. **DeepL 的 glossary 需 ≥1000 句对训练**（调研实据），科研小批量启动成本高；自建 LLM 术语库按词条即配即用
